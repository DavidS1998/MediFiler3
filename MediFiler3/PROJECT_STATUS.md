## Important implementation caveats

- Settings/layout initialize before MainWindow construction. WindowLayoutController captures on Closing before App flushes while the dispatcher/WinUI remain alive. Background persistence must not require a stopped dispatcher. Retain dirty state on failures and preserve unreadable settings/layout until a real change.
- Fullscreen uses transient layout suppression, not a saved window state. Its 40 ms cursor timer sees native HWNDs; top reveal switches the actual WPF WindowStyle and refits the same physical monitor rectangle. Native caption coordinates can be negative relative to the client origin: preserve the outer-window containment test to avoid title-bar flicker.
- Fullscreen left reveal is coordinated by MainWindow, not independent mouse-leave events. Keep tree pin state, offset, native-video exclusions and native surface ordering in sync. Native video cannot composite WPF translucency; preserve clipping rather than reviving the rejected tree-popup transparency experiment.
- `WinUiCarouselSettingsIsland` retains its old class/name but now hosts **the complete native Settings page**, not just a slider. New tests must wait for native controls to load and use their automation peers, not cast them to WPF Button/TextBlock.
- Reset a cancelled carousel item's ThumbnailTask when leaving Browse so a pending obsolete task cannot block new preview work on return. Fade-out visuals must never affect selection/hit testing or retain source handles.
- Root history uses normalized path keys; Undo scope uses filesystem identity. Do not unify them. Legacy NULL-scoped journal entries stay stored for recovery/inspection and are excluded from active-root history.
- Backup storage is `%LOCALAPPDATA%\MediFiler3\UndoBackups` on the destination volume, otherwise a hidden volume-root `.MediFiler3-UndoBackups-{SID hash}` directory. No sibling fallback if safe storage fails. Legacy `.MediFiler3-Undo-{guid}` siblings remain at recorded paths; no implicit migration.
- Cleanup appends HistoryDiscarded to whole owning groups before deletion. Locked deletion can leave a backup whose history is already retired; retry cleanup. Never prune backups by filename scan. ContentDialog needs its dedicated full-sized owned island and must finish/hide before disposal; cancel previews/late callbacks.
- Win32 monitor rectangles are pixels; layout dimensions/offsets are logical units. Preserve WINDOWPLACEMENT workspace/screen taskbar conversion and deferred Loaded maximization for ShowActivated=false windows.
